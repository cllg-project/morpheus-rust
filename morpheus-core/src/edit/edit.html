    Principal-part adjustments (only when a tense system is irregular)

    Enable a row only to override that tense system: give an irregular stem suffix and/or a different inflection pattern, or restrict it (e.g. middle only). Untouched systems are generated regularly.

    Restrict to specific forms / add form variants (@ lines)

    Each variant restricts the stem line to certain forms, or — with an explicit ending — adds a complete extra form (ending in Greek, e.g. ρσι for an extra dative plural).
